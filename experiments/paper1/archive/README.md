# Paper I archive

This directory contains first-version exploratory calculations that are not
current submission-facing claim support.

`isotypic_decomposition.py` compresses the ambient commutant into spectral
layers. Since the nontrivial `A`-spectral layers are not invariant under the
full transport action, its reported components must not be described as
`G`-isotypic subrepresentations without a separate valid construction.
