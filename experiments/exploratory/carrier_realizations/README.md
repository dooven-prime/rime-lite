geometry, and Selberg proxies are outside that package.

Paper VIII v2.1 consumes only the modular and bounded triangle JSON bundles
through a separate paper-owned promotion certificate. Package documentation,
Markdown projections, hostile controls, and excluded migration lineage do not
enter that promoted claim surface.
