# Historical Provenance Boundary

This scaffold was distilled from earlier local Paper VII and minimax
experiments. Those historical drafts, logs, and JSON files are not imported by
this implementation and are not present as a source-addressed dependency in
this directory. Do not treat them as active Paper VII evidence or as part of
the present certificate closure.

The active implementation was migrated into `rime-lite` on 2026-08-13. The
original local directory remains historical source material and is not a
runtime dependency. Migrated JSON results are regenerated in this repository;
old repository commits and producer digests are not carried forward as if they
identified the migrated execution. The retained migration certificate records
historical digests and comparison outcomes, but the public repository does not
contain the historical bytes needed to rerun that one-time comparison.

The migration audit ignores historical single-index overlap and containment
selectors when numerical ties occur. Those selectors depended on floating
eigensolver perturbations and were not stable alignment objects. Migrated
records replace them with tolerance-qualified sets of all maximizing or
minimizing sectors while preserving overlap masses, minimum residuals, frame
relations, and all routed-incidence census fields.

Known issues in the historical exploration included hard-coded absolute paths,
an incomplete count verifier, cross-family sector comparisons without
alignment, and numerical conjectures contradicted by the displayed data. The
current entry points are the files named in `README.md`. Package-local claims
are limited to `THEOREMS.md`, `RESULTS.md`, and generated records under
`results/`. Paper VII v2.1 separately owns only the fixed-frame subset named in
its paper-local registration; neither this provenance note nor the migration
certificate promotes any additional artifact.
