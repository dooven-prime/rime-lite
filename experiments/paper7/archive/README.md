# Paper VII Archive

These scripts are historical exploratory support for the first-version Paper
VII completion line. Active Paper VII v2 implementations live under
`../validation/`:

- `../validation/atlas_r2_boundary.py`
- `../validation/incidence_variety_codim.py`
- `../validation/rank_protected_bridge_audit.py`

Current generated records belong under `../results/`; repository-level
`data/` is internal and is not a public Paper VII artifact location.

Archived here:

- `search_type4_deep.py`
- `search_type4_nonregular.py`
- `search_type4_real.py`
- `search_type4_rho.py`
- `markov_graph_sof.py`

These are exploratory Type IV incidence searches in regular, non-regular,
rho-direct, real, and deep group-element settings. They ask whether the Type IV
incidence condition

```text
A != 0, B != 0, AB = 0
```

appears inside represented sectorized systems. That question belongs to Paper
VII's completion/incidence boundary program rather than Paper VI's moduli-wall
theorem layer.

The archived search scripts are background for the represented-system
incidence question. `markov_graph_sof.py` supported the removed cross-species
appendix. None is current Paper VII theorem or observation authority.
