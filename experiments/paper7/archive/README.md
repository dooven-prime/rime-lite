# Paper VII Archive

These scripts are historical exploratory support for the Paper VII completion
line. Active Paper VII support scripts live one directory up:

- `atlas_r2_boundary.py`
- `incidence_variety_codim.py`
- `rank_protected_bridge_audit.py`
- `markov_graph_sof.py`

Archived here:

- `search_type4_deep.py`
- `search_type4_nonregular.py`
- `search_type4_real.py`
- `search_type4_rho.py`

These are exploratory Type IV incidence searches in regular, non-regular,
rho-direct, real, and deep group-element settings. They ask whether the Type IV
incidence condition

```text
A != 0, B != 0, AB = 0
```

appears inside represented sectorized systems. That question belongs to Paper
VII's completion/incidence boundary program rather than Paper VI's moduli-wall
theorem layer.

The archived scripts are background for the represented-system incidence
question; they are not the main Paper VII computational proposition.
