# Finite Combinatorial Formalization Milestone

## Scope and identity

This separate Lean companion fixes the future-event behavioral classification
and exact finite count for every `n>=3`. The objects are states generated by
actual chronological `p,d` words from the singleton seed, with the selected
source pair `{0,1}`. The quotient is defined by equality of all future
selected-event traces, not by declaring the proposed normal forms equivalent.

The exact-byte record is
[`milestones/finite-combinatorial-v1/manifest.json`](milestones/finite-combinatorial-v1/manifest.json).
It is a local proof milestone, not a Git release, a new HAL submission, or a
change to the proof identity of `hal-05844771v1`. The repository HEAD records
context; source identity is given by the recorded SHA-256 entries, including
files not committed at that HEAD.

The frozen inputs include the complete local finite proof spine, its audit
entry point, the toolchain and dependency locks, and the replay scripts.
They do not include mutable explanatory documentation or the development
manifest, so a later, separately scoped proof layer can be documented without
rewriting this milestone. Replay rejects any change to a frozen input.

## Actual construction, not admission by definition

The following parameter types contain only finite combinatorial choices:

```lean
RegisterableParam n t :=
  Fin n × Select (n - 3) (t - 1) × Select (n - 1) (t + 1)

RegisteredPlacementParam n k :=
  Fin (n - 1 - k) × FiberParams n k
```

The audit separately records all four parameter definitions, including their
dependent sums. Their definition closures do not contain `PairGenerated`,
`PairRegisterable`, `RegisteredNonterminal` or `ReachableExecution`.

For registerable placements, actual outside-only assembly words start at the
singleton seed and retain the two selected singleton packets; fusion-free
placement adjustment realizes every remaining coordinate choice. Actual
source order recovers the cuts, physical sites and phase uniquely. The
forced first cut in the intermediate native encoding is removed by a pure
finite-set equivalence.

For registered nonterminal placements, the carrier choice fixes its source
arc. A canonical code supplies that arc through actual checkpoint execution,
and the pinned fixed-chain fibre construction supplies the target placement.
The reverse normal form is extracted from an actual history. Literal carrier
boundaries and unique rank parameters prove injectivity. The old chain and
origin are not additional coordinates of this placement count.

The executable audit requires the corresponding forward, reverse and
injectivity declarations to occur in each equivalence's transitive closure.
It also requires the final count to depend on the actual behavioral
classification and quotient equivalence.

## Closed finite conclusion

The cardinality results are

\[
R_n=n\binom{2n-4}{n-3},\qquad
A_n=2(2n-3)\binom{2n-4}{n-2}-n(n-1),
\]

and

\[
|\operatorname{FutureQuotient}(n)|=
1+n\binom{2n-4}{n-3}
+2(2n-3)\binom{2n-4}{n-2}-n(n-1).
\]

The additive count theorem justifies subtraction in `Nat`. The normal-form
map and parameter equivalences remain noncomputable mathematical objects;
this milestone does not extract a minimization algorithm.

## Separate analytic layer

The asymptotic statement

\[
Q_n^{\mathrm{future}}\sim
\frac{5}{16\sqrt\pi}\sqrt n\,4^n
\]

is not part of this finite milestone. Its entry point is the closed count
above; the paper-level normalization and pinned library inputs are separated
in [ASYMPTOTIC_HANDOFF.md](ASYMPTOTIC_HANDOFF.md). It requires a central-binomial
asymptotic and a polynomial remainder estimate. The full-summary observation
contract and its prefix-detection bridge also remain separate from this milestone.
