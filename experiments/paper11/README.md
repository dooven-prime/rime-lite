# Paper XI Experiments

This directory contains the current Paper XI evidence code and generated
records. Earlier census implementations are retained only as internal
provenance; they were not public manuscript versions or stable command-line
entry points.

```text
paper11/
|-- *.py          current evidence producers
|-- validation/   current validators and bounded domain audits
|-- results/      current typed records and observations
`-- archive/      retired census/PCA/density implementations and outputs
```

Only the current manuscript `papers/paper11/Paper XI.md` is the canonical
Paper XI text. Files under `archive/` are not current claim support and are not
imported by active validation.

## Census Versions

| Census | Role | Current claim authority |
|--------|------|-------------------------|
| `archive/wall_record_census.py` | original 24-record census | internal historical provenance |
| `archive/wall_record_census_v2.py` | 28-record extension | frozen typed-v3 migration input only |
| `validation/typed_wall_record_census.py` | corpus entries, strict/analogue morphology bundles, morphology atoms, realization/role/field-family separation, structured profiles, and multi-label curation | current manuscript |

The v3.6 typed migration verifies and reads the frozen
`archive/results/wall_record_census_v2.json` by SHA-256, reads
`results/wall_record_inclusion_ledger_v1.json`, and writes
`results/wall_record_census_typed_v3.{json,md}`. It preserves all 28
historical rows and retains 27 active rows. Five upstream-admitted `strict_sof`
bundles enter the strict main wall spectrum. Two included
`diagnostic_analogue` bundles remain in a separate morphology set without an
upstream strict-wall admission claim. Every morphology bundle contains one morphology atom in this snapshot, but the schema
does not identify bundle and atom counts. Record role and field family are
independent of realization kind; no analogue status is encoded as a role or
carrier. A trajectory event requires a present, typed, distinct primary
before/after pair and records raw-numeric, accessibility, and event-semantic
directions separately. A locus sample records incident-stratum germs without
intrinsic two-sided order. Each morphology atom separates its primary field
and carrier from context co-observations and retains field-local policy and
evidence refs.
The six historical mechanism families are nonexclusive full-name curation
assignments under `paper11-curation-tags-v1.0`, not partition classes. Each
row also records its source artifact owner;
Paper XI owns corpus inclusion, the derived morphology profile, curation tags,
and census certificate, not upstream wall admission or the imported source
result. Each included entry binds its evidence schema, SHA-256, producer,
producer SHA-256, and claim status. The collision-quotient and route-incidence
certificates additionally bind independent validators and validation
certificates.

The Markov and Kuramoto rows use
`results/markov_boundary.observation.json` and
`results/kuramoto_freezing.observation.json`. These are bounded cached
observations governed by `experiments/observation.py`; stale source hashes
block reuse. They are not compiler certificates and do not enter the strict
wall spectrum.

The CNOT result is a paired path-admissibility diagnostic. It records the
singular affine interpolation and an invertible fractional-unitary control
with an explicit continuous logarithm. It withdraws the historical interior
repair threshold and remains outside wall admission.

The retired PCA, density, original census, and extended census tables live
under `archive/`. They are not regenerated by the active command.

Run the current census from the repository root:

```bash
python experiments/paper11/validation/typed_wall_record_census.py
```
