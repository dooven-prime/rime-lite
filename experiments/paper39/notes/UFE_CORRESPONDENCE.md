# Placed Forward-UFE Correspondence

**Status:** supplementary comparison construction and proof for Paper XXXIX
Proposition 5.1. Paper XXXIX owns that proposition and Theorem 4.1; this
note supplies the construction details, not a second consumer specification.
No forest field, consumer read, or command is added. No verified wrapper
implementation, efficiency result, or expressivity separation is claimed.

## 1. Exact Comparison Boundary

Use the abstract UFE interface in Stevens--Ghidini,
[arXiv v2, Section 3](https://arxiv.org/html/2504.10246v2#S3): singleton
initialization, the current equivalence classes, the chronological ordered
input-pair list `unions`, and append of a valid effective union. These are
published interface properties, not new results here. The efficient and
imperative refinements in Sections 4--5 have stronger implementation results;
the wrapper below is not proved to inherit them.

Fix exactly the consumer's existing environment: Q, p, one defect d, its
binary kernel {k_0,k_1}, collision image c, atoms Omega, and injective singleton
seed iota. All fusions have the same label d, ports k_0,k_1, and target c.
These constants are already given data, not event annotations added to the
forest. Multiple defect letters would require a different comparison.

Fix a bijection e:Omega -> {0,...,N-1}. For a nonempty block B define
pick(B) to be its atom with least e-index. This is a deterministic adapter
convention, not a consumer read or a new forest field. Any fixed valid choice
would give the same decoded block events.

The ordered call contract is essential: whenever the packets B_0,B_1 at
k_0,k_1 fuse, call UFE union with

$$
 x=e(\operatorname{pick}(B_0)),\qquad
 y=e(\operatorname{pick}(B_1))
 \tag{UC-Call}
$$

in that order. The first and second stored input components thereby identify
the two kernel ports. This binding is proved for the wrapper's generated
calls; it is not inferred for an arbitrary pre-existing UFE history. Sorting
or forgetting the input-pair order would need an additional port annotation.
The UFE parent-pointer direction is not used as a kernel-port assignment.

## 2. Comparison State and Actual Update

Let Pi(u) be the partition of Omega pulled back from the current UFE
equivalence classes through e. The comparison state is

$$
 Y=(u,\ell),\qquad \ell:\Pi(u)\hookrightarrow Q.
 \tag{UC-State}
$$

The only added dynamic data are the current class placement ell. No fusion
tree, origin snapshot table, absorption list, raw word, or timestamp is stored
in Y. The initial state uses UFE initialization on N atoms and
ell({x})=iota(x). The finite fusion history is already part of u.

Decode the current placed partition by putting B at ell(B), for all B in Pi(u).
Call it P_Y. The wrapper executes a raw letter a as follows.

- If there is no collision on the full occupied support, leave u unchanged
  and put every B at f_a(ell(B)).
- If both kernel positions are occupied, let B_i be the class at k_i and
  append the effective union (UC-Call). Replace B_0,B_1 by B_0 union B_1 at c;
  put every other class B at f_d(ell(B)).

Denote this update by Move_a(Y). In the collision case the two UFE classes
are distinct and both arguments are valid indices, so the union is effective.
The binary-kernel hypothesis makes these the only two cases and guarantees
that the new placement is injective. All packets, including those unrelated
to a selected consumer event, are updated.

The comparison domain is the set of states Y_h generated by these rules from
the fixed seed over all finite raw words h. It is closed under p and d.
An arbitrary valid UFE state paired with arbitrary positions is not declared
to have the raw-event provenance required by the consumer.

## 3. Prefix-Class Decoder, Without Copying the Forest

Write the ordered effective-union list of u as
((x_1,y_1),...,(x_m,y_m)). Starting with singleton equivalence classes, let
Pi_i be the partition after the first i unions. For entry i, define

$$
 B_{i,0}=[e^{-1}(x_i)]_{\Pi_{i-1}},\qquad
 B_{i,1}=[e^{-1}(y_i)]_{\Pi_{i-1}},\qquad
 F_i=B_{i,0}\cup B_{i,1}.
 \tag{UC-Prefix}
$$

The classes are nonempty and disjoint, by effectiveness. They are computed
from the retained list and the fixed singleton seed, not saved as duplicate
forest fields. For Y_h, entry i is exactly the i-th fusion of h, with parents
B_{i,0},B_{i,1} at k_0,k_1. Induction on raw letters proves this: a nonfusion
appends nothing; a fusion appends precisely its two port-bound packet atoms
and merges precisely those classes. Thus P_{Y_h}=P_h as well.

Fresh blocks F_i are distinct. Once a block is created, later unions cannot
split it, and an effective union involving it adds a nonempty disjoint block.
Unions elsewhere cannot create that same fresh block. Therefore registration
can be read by

$$
 \operatorname{Reg}_U(Y,F)\iff \exists i\in\{1,\ldots,m\}:F_i=F.
 \tag{UC-Reg}
$$

This is not the weaker test that the current class contains F. For a registered
F, write i_F for its unique entry. Its origin snapshot assigns B_{i_F,j} to
k_j and records d,c. For every i>i_F, append a selected absorption precisely
when F is contained in one parent B_{i,j}. At most one parent contains F.
The record is

$$
 (d,k_j,B_{i,j},k_{1-j},B_{i,1-j},c,F_i).
 \tag{UC-Abs}
$$

The current carrier is (ell(C),C), where C is the unique current class
containing F. Let K_U(Y,F) be P_Y, F, the decoded origin, and this complete
ordered absorption list. It is the whole consumer summary, not just a report.

For every history h and nonempty F,

$$
 \operatorname{Reg}_U(Y_h,F)\iff\operatorname{Reg}(h,F),\qquad
 K_U(Y_h,F)=U(h,F)\quad\text{when registered}.
 \tag{UC-Read}
$$

The prefix induction identifies every parent block and its port. Scanning the
retained chronological list after i_F selects exactly the log subsequence in
the independent specification. Its current class and placement identify the
same carrier. This proves (UC-Read) for all requested fields, without a
forest-based read-table definition of the task.

The list index i counts effective unions, not raw generator occurrences.
It is used internally in the decoder and is not returned as an absolute
timestamp. Plateau history need not be recovered.

## 4. Representation Decoder to the Existing Forest

For comparison, define J_F(Y) by an auxiliary fold over the same list. Begin
with singleton leaf trees. At entry i replace the trees on B_{i,0},B_{i,1}
by the node with children indexed k_0,k_1 and event data d,c. At the end,
place each current tree on B at ell(B). The marker is absent for m=0 and is
the node created at the last entry otherwise, whether or not it is a root.
This fold is a mathematical decoder, not retained UFE state or an execution
of `Explain`.

The prefix correspondence above yields

$$
 J_F(Y_h)=z_h,\qquad
 J_F(\operatorname{Move}_aY)=\delta_a^{\mathfrak F}(J_FY)
 \quad(Y\text{ generated}).
 \tag{UC-Forest}
$$

For a nonfusion, the fold's trees and marker do not change and all current
positions do. For a fusion, appending the effective union constructs exactly
the new binary node from the two existing trees at their actual kernel
positions; the latest marker is that node. No earlier node disappears.
These are exactly the forest equations, including the marker rule.

The map J_F is onto the seed-generated forest domain: choose the same history
h for any z_h. No injection, inverse state map, or byte-for-byte identity with
UFE's internal parent-pointer forest is claimed. UFE's full union-list order
contains data not requested by this consumer and not explicitly retained as
a total ordering of incomparable forest events.

## 5. Complete Command Correspondence

At (Y,F), require (UC-Reg). Determine the current carrier from K_U(Y,F) and
compute its collision group using the complete P_Y and the raw action.
Enable Carry(a) or Absorb(a) by exactly the independent consumer's singleton
or two-point condition. For the enabled command execute Move_a and retain
the same F. Neither command is enabled outside registration.

This uses UFE initialization/union and placement updates; Carry and Absorb
are adapter programs, not names of native UFE operations.

For invocation-level equations, use K_U on pairs and write
tilde-J_F(Y,F)=(J_F(Y),F). This retains the same selected argument and avoids
applying the state-only decoder to a command invocation.

For every generated Y, registered F, and requested command alpha,

$$
 \begin{aligned}
 \Delta^U_\alpha(Y,F)\downarrow
   &\iff \Delta_\alpha(K_U(Y,F))\downarrow,\\
 K_U(\Delta^U_\alpha(Y,F))
   &=\Delta_\alpha(K_U(Y,F))\quad\text{when defined}.
 \end{aligned}
 \tag{UC-Command}
$$

**Proof.** (UC-Read) supplies the same full partition, current carrier, and
labelled action to both guards. Their collision groups are identical, proving
definedness in both directions.

For Carry(p), u is unchanged and placement moves. For Carry(d) with no
collision, the same is true under d. For Carry(d) with a collision elsewhere,
Move_d must append that unrelated effective union and update the full
partition: neither parent contains F, so the decoded selected absorption
list remains unchanged. The selected carrier still moves by d. For Absorb(d),
one parent is the current carrier and the other is its disjoint partner;
the appended entry adds exactly (UC-Abs), with the same event addresses and
new carrier at c. Absorb(p) is not enabled. The retained list preserves the
origin entry and F, hence registration persists. These cases prove the full
successor equality, not only report agreement. $\square$

The same guard calculation and (UC-Forest) give equality of the legal domains
and the commuting successor diagram between the UFE adapter and the forest
commands, using tilde-J_F on invocations. With J_C the existing
forest-to-consumer decoder,

$$
 K_U(Y,F)=J_C(J_F(Y),F).
 \tag{UC-Triangle}
$$

Finite command paths lift from each actual Y, with its actual successive UFE
states and the same F: use (UC-Command) at each successor. No representative
is chosen again from a decoder fiber between commands. Surjectivity onto
generated consumer summaries follows by taking Y_h for the history of each
U(h,F).

## 6. Atom Renaming and Finite Data

Under eta:Omega -> Omega', use e'=e eta^{-1}, iota'=iota eta^{-1}, F'=eta(F),
and ell'(eta(B))=ell(B). The selected least e-index atoms have the same
numeric UFE identifiers on both sides. Therefore union input lists coincide
numerically, decoded atom blocks are renamed, and positions, d, and c remain
fixed. Registration, reports, guards, and command successors transport.
This proves the requested comparison; it is not arbitrary relabelling of the
underlying coordinate action.

The effective-union list has length at most N-1. The selected absorptions
still satisfy the existing bound N-|F|. The adapter adds current placement,
not an unbounded plateau counter or execution word. No complexity claim for
the prefix decoder follows: it may recompute classes from the whole list.

## 7. Completion and Explicitly Declined Stronger Claims

| Comparison | Disposition |
|---|---|
| Forward abstract UFE plus current placement and the ordered-port call contract -> full named consumer | CLOSED: registration, all reads, both command domains, successors, and continuous realization |
| The same adapter -> the seed-generated forest | CLOSED: surjective decoder and update commutation; not a state isomorphism |
| Bare UFE with no placement -> all current-coordinate reports | Not asserted; the adapter explicitly supplies placement |
| Arbitrary UFE histories -> certified raw event histories | Not asserted; only the wrapper's seed-generated domain is used |
| Full API equivalence including rollback and equality-proof queries | Declined as outside this forward-consumer comparison |
| Efficient/imperative implementation of the placement wrapper | Not implemented or verified; no inherited total-correctness or complexity guarantee |
| Expressivity separation or independent novelty from UFE | Not established; the positive construction makes annotated-history realizability explicit |

The representation/command question is thus not left open merely because
the APIs have different names. The supplied consumer is realizable as a
placed forward-UFE history consumer on the declared domain. Its forest
adequacy remains valid, but it must not be promoted as an expressivity
advantage over that adapter.

This comparison supplies neither historical typed-transfer identification nor
a whole-image entrance, projectability result, or reset bound. The independent
consumer specification remains the same.
