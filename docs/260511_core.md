## Two Governing Principles

### Principle 1 — Noncommutative Simple Components Govern Everything

> **M₂ Principle.** Noncommutative simple components (n_i ≥ 2 in the AW decomposition) are the sole carriers of refinement obstruction, transport mediation, and Lie curvature. M₁ components are spectators on all three levels.

### Principle 2 — Discrete Composition Exceeds Infinitesimal Realization

> **T7 Principle.** Lie accessibility is block-preserving — commutators cannot couple sectors from different simple-component blocks. Discrete composition can mediate through hybrid projectors (primitive sectors whose support spans multiple blocks) — the projector interleaving P_α ρ(g) P_γ ρ(h) P_β bridges what no single ρ(g) can. The continuous limit collapses cross-block support chains to intra-block curvature.

**These two principles are the theorems.** Everything below is their definition, instantiation, and evidence.

## Four Objects (Abstract)

### Object 1 — Averaging Algebra

```
G: finite group
(V, ρ): finite-dim unitary representation
S ⊂ G: inverse-closed generator subset
A_S = (1/|S|) Σ_{s∈S} ρ(s) — Hermitian averaging operator
⟨A_S⟩: *-algebra generated by {A_S}
```

Different S produce different A_S. These generate the refinement poset.

### Object 2 — Spectral Sectors

A spectral decomposition D(A_S) = {E_λ = im(P_λ) : λ ∈ spec(A_S)} partitions V.

Given a set of **commuting** averaging operators {A_S₁, ..., A_S_k}, joint diagonalization yields **primitive sectors** — the finest simultaneous eigenspaces:

```
D_center = D(A_S₁) ∧ D(A_S₂) ∧ ... ∧ D(A_S_k)
```

**Refinement poset L**: D₁ ⪯ D₂ ⇔ every projector of D₂ is a sum of projectors of D₁. The commutative core C is always a ∧-semilattice (meets exist). Joins exist only when the relevant operators commute.

### Object 3 — Transport Morphisms

```
T_αβ(g) = P_α ρ(g) P_β : E_β → E_α
```

These are the generating morphisms of the transport support category. Composition involves **projector interleaving**:

```
P_α ρ(g) P_β ρ(h) P_γ ≠ P_α ρ(gh) P_γ
```

The projector P_β obstructs group multiplication closure. The transport support graph is **not transitively closed** — mediated paths exist where direct edges do not.

### Object 4 — Lie Generators

```
A_g = log ρ(g) — principal matrix logarithm
```

The Lie algebra g = span{A_g : g ∈ G} generates accessibility at increasing depth:

```
κ₀(α,β) = max_g ‖P_α A_g P_β‖          — gradient (individual generators)
κ₁(α,β) = max_{g,h} ‖P_α [A_g, A_h] P_β‖ — curvature (commutators)
κ_d(α,β) = max ‖P_α C_d P_β‖            — depth-d Lie monomials
```

ρ(g) block-diagonal ⇒ A_g block-diagonal ⇒ [A_g, A_h] block-diagonal ⇒ **Lie accessibility is block-preserving at all depths**.

## Invariant — Noncommutative Support Profile (Supp_nc)

The AW decomposition of the averaging algebra is the central algebraic object:

```
⟨A_S⟩ ≅ ⊕_i M_{n_i}(ℂ)
```

Define the **noncommutative support** of a sector S_α:

```
Supp_nc(S_α) = {i : n_i ≥ 2, P_α has nonzero projection onto M_{n_i}(ℂ)}
```

M₁ components are **spectators**: they carry no curvature (κ₁=0), permit unrestricted refinement, and have K=0 with all other sectors unless bridged through an M_{≥2} component.

### What Supp_nc Determines

| Phenomenon | Supp_nc rule |
|-----------|-------------|
| Direct transport (K_αβ > 0) | Supp_nc(S_α) ∩ Supp_nc(S_β) ≠ ∅, or shared commutative block structure |
| Spectator isolation (K=κ₀=κ₁=0) | Supp_nc = ∅ and no shared commutative block |
| Curvature (κ₀=0, κ₁>0) | Supp_nc disjoint, but within the same simple-component block family |
| Cross-block freezing (T7) | Supp_nc in different blocks → κ_d=0 ∀d, but discrete chains may exist |
| Hub | Minimal family H with ∪_{α∈H} Supp_nc(S_α) = all active n_i≥2 components |

**Supp_nc is the single invariant.** Transport graph, hub degree, mediation count, curvature channels — all are shadows of this map. It depends only on the AW decomposition, not on group geometry.

## Instantiation 1: S₃ — Minimal Prototype (9-dim and 12-dim)

The smallest non-abelian group (order 6) already exhibits both governing principles.

### S₃ nat⊕reg (9-dim) — T7-Only

```
ρ(g) = block_diag(ρ_nat(g), ρ_reg(g))
A_full = avg over all 6 S₃ elements
Center = {A_full, A_trans} joint diagonalization
```

| Sector | dim | Block | Supp_nc |
|--------|-----|-------|---------|
| S2 | 2 | reg | ∅ |
| S3 | 1 | nat | ∅ |
| S4 | 1 | reg | ∅ |
| S5 | 4 | nat+reg HYBRID | ∅ |

**Result**: 3 T7 pairs, all cross-block (nat↔reg), mediated through hybrid S5. κ₁=0 everywhere (no M₂). T7 exists WITHOUT curvature — M₂ is NOT necessary for T7.

### S₃ reg⊕reg (12-dim) — Full Hierarchy

```
ρ(g) = block_diag(ρ_reg(g), ρ_reg(g))
Generators = {3 transpositions}
Center = {A_3, A_2} joint diagonalization
```

| Sector | Block | Type |
|--------|-------|------|
| S1-S9 | Pure A or B | Within-block only |
| S10 | A+B HYBRID | Spans both blocks |

**Result — perfect separation of all three coupling types:**
- **30 Class-II edges** (κ₀>0): ALL within-block
- **10 curvature pairs** (κ₀=0, κ₁>0): ALL within-block
- **9 T7 pairs** (K=κ₀=κ₁=0): ALL cross-block, mediated through S10

Zero counterexamples. Curvature ⊂ within-block. Cross-block = composition-only.

### What S₃ Proves

1. T7 is generic, not Rubik-specific — S₃ at 9-dim already exhibits it
2. M₂ ⇒ curvature, but M₂ ⇏ T7 — T7 requires a hybrid projector (C2) spanning both blocks, not noncommutativity
3. M₂ and T7 are **two distinct obstruction types**: M₂ = refinement/curvature carrier; T7 = decomposition mismatch (sectors transverse to blocks)
