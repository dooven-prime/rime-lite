# Registered Absorption Chains (HAL v1)

The [HAL preprint hal-05837829v1](https://hal.science/hal-05837829v1)
is *Registered Absorption Chains and Placement Fibers for a Circular Action
with an Adjacent Idempotent* by WuJun Chen. This directory retains the
author's local HAL reader PDF as a repository byte snapshot. The HAL record,
not this repository copy, determines the public deposit identity.

The PDF was copied byte-for-byte from the local HAL build output. Its byte
identity with the file served by HAL has not been independently checked here.
These are the local source files accompanying the HAL build. Dated editing
snapshots and exploratory proof notes are not part of this snapshot. The PDF
is the frozen reader artifact; byte-identical regeneration from these text
files is not claimed by this repository snapshot.

The later [GitHub companion](../../../experiments/registered_absorption_chains/README.md)
contains bounded raw-action replay and a separately identified
[Lean formalization milestone](../../../experiments/registered_absorption_chains/FORMALIZATION_MILESTONE.md).
The Lean theorem covers the exact count of generated registered summaries;
the preprint's asymptotic growth corollary is not machine-checked there.
Neither companion was part of the HAL v1 deposit.
