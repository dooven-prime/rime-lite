The core results determine the complete one-block partition-fibre amplitude
and the exact maximum over every all-upper actual observation, allowing
whole-packet transfers and arbitrary event interleavings. The singleton
forest theorem retains a joint structural defect and the original extraction
deficit. Appendix A supplies the moment-sensitive physical terminal route.

This second local candidate subsumes the earlier comb-only extension. It
preserves that earlier worktree and ZIP rather than rebinding their source
identity. The remaining global comparison concerns multiblock observations
with lower-layer survivors, not unresolved all-upper tree shapes.

From the repository or standalone source-archive root:

```sh
python -B experiments/paper47/validation/build_reader.py
```

The builder uses the numbered-paper TeX pipeline with paper-local 22 mm
margins. Its fixed profile and build receipt are
in the experiment package. This is a candidate, not a published or
submitted release; no publication tag or archive identity is assigned.
