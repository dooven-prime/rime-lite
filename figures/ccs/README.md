# CCS Figures

`render.py` is the active presentation-only entry point for the RIME
Computational Companion Archive.

Run from the repository root:

```bash
python figures/ccs/render.py
```

The renderer reads the source-addressed Paper I and Paper II display records
and produces five current figures:

| Figure | Subject |
|--------|---------|
| `fig_c1_canonical_spectrum` | Registered blockwise spectral census |
| `fig_c2_transport_heatmap` | Registered direct transport matrix |
| `fig_c10_phase_cancellation` | Local exact roots-of-unity identity |
| `fig_c19_direct_support_graph` | Ten-edge aggregate direct-support graph |
| `fig_c20_arithmetic_contrast` | Finite generator-family arithmetic contrast |

These images are archive visualizations, not executable certificates. Their
scientific inputs remain under `experiments/paper1/results/` and
`experiments/paper2/results/`.

Figure C14 remains in the archive as a semantically bounded static localizer
display. It is not regenerated by `render.py` and is not a direct-graph
certificate.

Figures C12 and C13 remain bounded historical generator-family
visualizations. Their field labels record numerical recognition along declared
finite families; they do not establish an exact field-classification or
mathematical phase-transition theorem and are not part of the current CCS PDF.

Older C-series figures remain in this directory for historical release
compatibility. Replaced versions and retired Paper I--III atlases are preserved
under `historical/`. The all-in-one legacy builder is
`figures/archive/ccs_figures.py` and must not be used as the active CCS build.
