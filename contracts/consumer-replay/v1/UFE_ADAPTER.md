# Placed Forward-UFE Adapter

This is a second representation of the same consumer, not an identification
with an older typed characteristic. It uses a forward abstract union-find
with an ordered list of **effective** union input pairs. It does not assume
that a native `Explain` result or a bare parent-pointer forest contains
all consumer data. Rollback and imperative refinement are outside v1.

## State and Ordered-Port Call Contract

Choose a bijection `e:Omega -> {0,...,N-1}` from the declared
`ufe_enumeration`. Let `u` be the abstract UFE state initialized with
singleton classes and an empty ordered union list. Let `Pi(u)` be its
current atom partition. The comparison state is

```text
Y = (u, ell),  ell:Pi(u) -> Q injective.
```

`ell` is the current placement of **every** class. No forest, origin
snapshot, absorption report, raw word, or timestamp is stored in `Y`.
The fixed action `d`, ports, and target are environment constants, not
annotations inferred from arbitrary union histories.

On a raw nonfusion step, leave `u` unchanged and move every class placement
by `f_a`. On a `d` fusion, let `B_0,B_1` be the distinct current classes at
`k_0,k_1`. Pick one atom from each by the least `e`-identifier, then append
the **ordered** effective UFE call

```text
union(e(pick(B_0)), e(pick(B_1))).
```

Replace those classes by `B_0 union B_1` at `c` and move every other class
by `d`. The first stored input binds the `k_0` parent, the second binds the
`k_1` parent. Sorting or forgetting those two inputs loses the event-port
contract. The adapter domain is the states generated by these updates from
the declared singleton seed; an arbitrary UFE state with arbitrary
placements is not certified as a raw execution.

## Prefix-Class Decoder

Write the chronological UFE input list as
`((x_1,y_1),...,(x_m,y_m))`. Recompute the partition `Pi_{i-1}` after the
first `i-1` unions. At entry `i` define

```text
B_{i,0} = class of e^{-1}(x_i) in Pi_{i-1},
B_{i,1} = class of e^{-1}(y_i) in Pi_{i-1},
F_i = B_{i,0} union B_{i,1}.
```

The call contract identifies these blocks as the actual parents at
`k_0,k_1`. The `F_i` are distinct. Register a supplied nonempty `F`
exactly when `F = F_i` for one entry `i_F`; current containment alone is
insufficient. Its origin is the local record at `i_F`.

For every later entry `i > i_F`, append one selected absorption precisely
when `F` lies in one of `B_{i,0},B_{i,1}`. That parent is the carrier; the
other is its partner. The fixed `d,k_0,k_1,c` and the prefix blocks yield
all event-time addresses and blocks. The **current** carrier is the pair
`(ell(C),C)`, where `C` is the current class containing `F`. The complete
state also retains the placed partition from all current classes. UFE list
indices count fusion events, not raw time or plateau steps.

Folding the same ordered union list into binary nodes, using the fixed
port contract and `ell` on current roots, defines a surjective decoder to
the seed-generated forest. It need not be injective: the UFE list orders
independent fusions that a forest need not order globally.

## Commands and Boundary

At a registered `(Y,F)`, compute the collision group from the **full**
placed partition and current carrier. Enable `Carry(a)` or `Absorb(a)` by
the consumer specification's exact guards. On an enabled command, execute
the actual UFE/placement update and keep the **same** `F`. For
`Carry(d)` with a fusion elsewhere, append that unrelated effective union
and update all placements, but do not add a selected absorption. For
`Absorb(d)`, append the union involving the selected carrier and decode its
new outer absorption. This yields the same registration, report, command
domain, and successor as the log oracle and forest on the generated domain.

An atom bijection transports `e`, the seed, placement, and selected `F`
together. It does not relabel `Q,p,d` or infer port assignments for an
unrelated UFE history. The mathematical correspondence is a forward,
surjective decoder and command simulation, not an isomorphism with bare UFE,
an efficient executable adapter certificate, or a proof of independent
novelty. A finite checker may implement and compare this route without
inheriting the UFE paper's machine-verification guarantees.
